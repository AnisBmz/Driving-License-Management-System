# Driving-License-Management-System

A desktop management system developed for the Driver and Vehicle Licensing Department (DVLD).
This project is built using C# .NET Framework and WinForms, designed to manage all processes related to local and international driving licenses.

🔷 Core Modules:
▪️👤 People & Users Management
▪️🔐 Login & Account Settings
▪️📑 Application Types & Test Types
▪️🪪 Local Driving Licenses Issuance & Renewal
▪️🌍 International Driving Licenses Issuance
▪️🔄 Replacement for Lost/Damaged Licenses
▪️⚖️ Detain & Release Licenses

🔷 Technologies Used:
▪️C# .NET Framework
▪️WinForms UI
▪️SQL Server Database
▪️ADO.NET CRUD Operations
▪️Three-Tier Architecture
